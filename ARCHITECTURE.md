## ??? Arsitektur Data Flow

```
SOURCE SYSTEMS
  CRM System (simulasi)        ? customers_YYYYMMDD.csv  ? data/raw/customers/
  Inventory System (simulasi)  ? products_YYYYMMDD.csv   ? data/raw/products/
  Orders App API (simulasi)    ? MongoDB documents        ? byk_mongo_orders

AIRFLOW PIPELINE (Extract & Load)
  Baca CSV + baca MongoDB ? Load ke Postgres DWH schema: raw

dbt TRANSFORM
  raw ? staging ? intermediate ? marts

MARTS (siap di-query analyst)
  fact_daily_sales | dim_customers | dim_products
```

## ??? Database Layer

### Postgres DWH — 3-Layer Schema

| Schema | Isi | Diisi oleh |
|---|---|---|
| `raw` | Data mentah dari source, tidak diubah | Airflow (EL) |
| `staging` | Data di-clean, di-cast type, di-rename | dbt staging models |
| `marts` | Fact & dimension tables siap pakai | dbt mart models |

### MongoDB — Orders Collection

- **Database:** `belanja_yuk_orders`
- **Collection:** `orders`
- **Schema:** `{ order_id, customer_id, order_date, status, payment_method, items[] }`
- **validationAction:** `warn` (bukan error) ? dirty data tetap masuk, tapi ada log warning
- **Indexes:** `order_id` (unique), `customer_id`, `order_date`, `status`

## ?? Data Dummy (Generated by Faker)

| Source | Format | Volume | Periode |
|---|---|---|---|
| Customers | CSV (`customers_YYYYMMDD.csv`) | ~2.000 baris | Static |
| Products | CSV (`products_YYYYMMDD.csv`) | ~300 baris | Static |
| Orders | MongoDB documents | ~20.000 docs | 90 hari terakhir |

### "Data Kotor" yang Disengaja

| Tipe Kotor | Contoh | Harapan |
|---|---|---|
| Email invalid | `budi@@mail` | Ditolak di staging / quality gate |
| customer_id tidak ada di master | `CUST9999` | Di-flag sebagai orphan |
| Order duplikat | `order_id` sama dua kali | Deduplicated di staging |
| Produk dengan harga 0 | `unit_price: 0` | Caught oleh dbt test |
| null di kolom wajib | `status: null` | Caught oleh not_null dbt test |

## ?? Tech Stack Decisions

| Teknologi | Pilihan | Alasan |
|---|---|---|
| Orchestrator | Airflow 2.9.3 (vanilla Docker) | Lebih "dari scratch" = lebih impressive |
| Alternative | Astro CLI | Untuk yang mau coba cepat |
| Transform | dbt Core | dbt Cloud limitasi di free tier |
| DWH | Postgres 15 | Gratis, lokal, dbt adapter native |
| Orders Source | MongoDB 7 | Simulasi real-world backend app |
| Alerting | Slack webhook | Gratis, profesional |
| Data Gen | Faker (Python) | Bisa generate realistic Indonesian data |
| CI/CD | GitHub Actions | Gratis untuk public repo |
| Docs | Bilingual ID + EN | README ID lokal, code EN global |
